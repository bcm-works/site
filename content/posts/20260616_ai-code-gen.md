With the rise of AI Code Generation tools, this quote from [an IBM Training Manual in 1979](https://www.ibm.com/think/insights/ai-decision-making-where-do-businesses-draw-the-line) remains relevant today:

> A computer can never be held accountable, therefore a computer must never make a management decision.

There's no doubt that these tools have increased the amount of code that can be produced, but the real issues arise when you actually consider the technical quality of the output.

I don't see this as the *end of Software Engineers*, as the hard part of building quality software is the decisions made beforehand that have shaped the *why* and *how*. This will always be done best by a human.

When these tools are used sparingly to prototype new ideas, based on a clear technical design, they can cut out a lot of boilerplate setup and help resolve common tooling and framework issues.

The impact to the software industry is massive, especially for the expectations for a Junior Software Engineer role.

As long as a junior has a decent handle on software engineering fundamentals and is eager to learn, there will always be room for them in various teams and companies.
